# Encryption Key Management

This directory contains encryption key policy artifacts and sample key metadata.

Files:
- `README.md` - encryption usage guidance.
- `encryption_key_template.txt` - sample symmetric key placeholder.
- `rotate_encryption_key.sh` - helper for key rotation in development.

## Notes
- Use a secure vault or key management service for production encryption keys.
- Keys should be rotated periodically and audited.
