# Signing Key Management

This directory contains signing key policy artifacts for JWT and message signing.

Files:
- `README.md` - guidance for signing key usage.
- `signing_key_public.pem` - sample public key for verification.
- `signing_key_private.pem` - placeholder private key metadata (not real key material).

## Notes
- Never commit real private signing keys.
- Store signing keys in secure secrets management infrastructure.
